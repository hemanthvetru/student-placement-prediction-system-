# Student Placement Prediction System

A browser-based placement readiness app that predicts whether a student may get placed using CGPA, coding skills, communication skills, internship experience, attendance, resume quality, and interview readiness.

## Features

- Placement probability prediction
- Resume score analyzer
- Interview readiness score
- Factor-wise score breakdown
- Personalized improvement recommendations
- Responsive shadcn-inspired UI

## How to Run

Open `index.html` in a browser.

No installation or build step is required.

## Prediction Factors

| Factor | Weight |
| --- | ---: |
| CGPA | 20% |
| Coding Skills | 25% |
| Communication Skills | 20% |
| Internship Experience | 10% |
| Attendance | 10% |
| Resume Score | 10% |
| Interview Readiness Score | 5% |

## Project Files

- `index.html` - Application layout
- `styles.css` - shadcn-inspired visual styling
- `app.js` - Prediction, resume, interview, and recommendation logic
